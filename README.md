### Hi, I'm Vinay Roy

I build AI agents for real business problems and publish the code.

Every project starts the same way: I hit a real product decision, build the smallest version that works, put evals on the behavior that matters, and write up the trade-offs. The code goes in **[applied-ai-agents](https://github.com/roy-vinay/applied-ai-agents)**. The reasoning goes in **[ai-decision-log](https://github.com/roy-vinay/ai-decision-log)**.
